# Homebrew Tap

Install Teams Mute Helper:

```sh
brew trust m-rk/tap
brew tap m-rk/tap
brew install --cask teams-mute-helper
```

Older Homebrew versions that do not have `brew trust` can skip the first command.

The app's source, releases, and setup guide are in [`m-rk/ms-teams-mute-shortcut`](https://github.com/m-rk/ms-teams-mute-shortcut).
