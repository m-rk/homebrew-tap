# m-rk Homebrew tap

Homebrew formulae and casks for projects published by [`m-rk`](https://github.com/m-rk).

## Set up the tap

```sh
brew trust m-rk/tap
brew tap m-rk/tap
```

Older Homebrew versions that do not have `brew trust` can skip the first command.

Once the tap is set up, packages can be installed by name.

## Available packages

### Teams Mute Helper

A signed and notarized macOS menu bar app for toggling Microsoft Teams mute with a global keyboard shortcut.

```sh
brew install --cask teams-mute-helper
```

Source, releases, and setup instructions: [`m-rk/ms-teams-mute-shortcut`](https://github.com/m-rk/ms-teams-mute-shortcut)
